# V1_OUT_OF_SCOPE_TASK-003

## 1. 目的

- 明确 V1 禁入能力，防止 TASK-004 实现阶段范围漂移。
- 所有排除项均基于 `rules/FORMAT_RULEBOOK_v2.md` 与 TASK-002 对齐/决策日志。

## 2. 明确不进入 V1 的能力（Out of V1）

1. 封皮模板重建与精确布局回写（含 logo/坐标/间距重建）。
2. 自动目录域重建与全量修复。
3. 正文起始分节+页码系统重构。
4. 脚注按页重编编号。
5. 奇偶页差异版式自动重构。
6. 参考文献内容级纠错、复杂排序重排、语言分组自动改写。
7. 装订线版面重排。

## 3. A 类中暂不进入 V1 自动修复的条目（降级为 Report Only）

1. 目录内容样式统一（FR-4.6-02）。
2. 主标题/副标题样式修复（FR-4.7-01/02）。
3. 一级/二级/三级标题样式与行距修复（FR-4.8-03/04/05）。
4. 正文普通段落样式全量修复（FR-4.9-01）。
5. 脚注字体字号行距修复（FR-4.10-02/03/04）。
6. 参考文献条目样式全量修复（FR-4.11-02）。
7. 常规页边距写回（FR-4.13-02）。
8. 页眉页脚样式写回（FR-4.14-01/02）。

## 4. 降级原因（统一口径）

- 高置信度块定位尚未落地：误识别会导致跨区块误改。
- 分节/页眉页脚/页码/脚注对象联动风险高：误改后回滚成本高。
- TOC、脚注、页码属于 Word 域与分页耦合对象：V1 不做结构重建。
- 参考文献规则含内容与语义判断，不符合 V1 “低风险、确定性、稳定识别”原则。

## 5. TASK-004 实现守卫建议

1. 固定 `AUTO_FIX_RULE_IDS` 白名单，代码层面禁止白名单外写回。
2. 对分节、目录域、脚注编号相关写操作添加运行时硬拦截并抛出 `OutOfV1Error`。
3. 报告层增加 `excluded_by_scope=true` 字段，展示被范围策略排除的规则。
4. CI 增加“越界检测”测试：若新增 fix 规则不在白名单则失败。

## 6. 升级触发条件（V1 之后）

- 已具备稳定的 TOC 域与脚注对象解析/回写能力，并通过回归集验证。
- 已具备分节与页码联动的可回滚写回机制。
- 已补齐封皮结构化解析证据（非 OCR 猜测），并完成规则复核与变更审批。
