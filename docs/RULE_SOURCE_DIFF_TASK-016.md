## 4. 新增规则

1. 英文不能有书名号《》
- 规则类型：英文标点与字符集规范。
- 规则分层建议：B（自动检查，不默认全局自动改写）。
- 依据归属：**项目补充冻结规则**（非新增管理办法 PDF 直接明文）。
- 原因：跨正文/标题/参考文献多区域，自动替换可能引发语义与引号冲突，先以审查规则冻结。

2. D 类参考文献不能有页码
- 规则类型：参考文献类型约束（类型与字段一致性）。
- 规则分层建议：B（自动检查，不默认自动改写）。
- 依据归属：**新增管理办法 PDF 直接支持**（附录参考文献模板中 `[D]` 格式为“作者. 论文题目[D]. 保存地点；保存单位，年份”，未给出页码字段）。
- 原因：当前 `FR-4.11-03` 是结构模板校验，未做“按类型字段可选性”细分；先补入检查口径，避免误删字段。

## 6. 冲突或歧义点

1. D 类页码与旧源冲突
- `8. 毕业论文正文写作格式要求.docx` 中 D 类示例含页码（如 `...[D]. 苏州大学, 2011, 98-100.`）。
- 本轮按新增管理办法 PDF（附录模板）优先级执行，冻结为“D 类不能有页码”。
- 结论：判定为“口径升级（以新增管理办法优先）”。

2. 英文禁用《》的适用域
- 歧义在于仅限“英文标题/摘要/关键词”还是“所有英文上下文（含参考文献英文条目）”。
- 本轮冻结范围：凡被识别为英文上下文均不应出现《》《》；边界不清时只报不改。
- 依据说明：当前未在新增管理办法 PDF 中检出该条直接明文，归为项目补充冻结规则。
