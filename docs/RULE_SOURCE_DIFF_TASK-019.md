# RULE_SOURCE_DIFF_TASK-019

## 1. 本轮新增规则源

- 新增纳入规则依据体系的学校文件：
  - `rules/sources/sample_undergraduate_thesis_policy.pdf`
- 实际核验结果（基于本轮读取）：
  - 文件实体存在且可读（`file` 识别为 PDF 1.3）。
  - 当前环境无法对该文件进行稳定 OCR；`textutil` 仅能读取 PDF 二进制流而非可引用正文文本。
  - 因此，本轮将其作为“正式来源已纳入”的依据文件，同时把可执行规则判断锚定在可抽取文本源与既有对齐文档中。

## 2. 与旧规则源一致的内容

基于已读取文件：
- `rules/sources/example_thesis_guideline.docx`
- `rules/sources/FORMAT_RULEBOOK_v1.md`
- `rules/FORMAT_RULEBOOK_v2.md`
- `rules/FORMAT_RULEBOOK_v3.md`（升级前版本）

一致项如下：
- 论文结构与排版主框架（摘要、关键词、目录、正文、参考文献、致谢、页面设置、装订顺序）延续 v2/v3 主干。
- A/B/C 分层边界继续有效，且 `docs/IMPLEMENTATION_SCOPE_TASK-003.md`、`docs/V1_OUT_OF_SCOPE_TASK-003.md` 仍要求高风险项不进入自动改写。
- 参考文献仍采用“类型标识 + 结构模板”口径，且保留“英文文献在前、中文在后”等检查型约束。

## 3. 新增或更明确的可执行规则

本轮冻结新增/收紧两条：

1. 英文中不能使用中文书名号《》
- 适用范围：英文正文、英文摘要、英文关键词、英文目录、英文参考文献。
- 工程动作：发现即报异常，不自动替换。
- 分类：B（自动检查，不直接修改）。

2. D 类参考文献不能带页码
- 适用范围：`[D]`、`[D/OL]` 等 D 类条目。
- 工程动作：条目尾部含页码/页码区间时报异常。
- 分类：B（自动检查，不直接修改）。

## 4. 仅属管理性/流程性、不纳入引擎的内容

结合新增学校policy document文件名定位（“policy document”）与现有实现边界文档，本轮继续不纳入引擎的管理流程类内容包括：
- 任务组织、提交流程、阶段性管理要求等管理条款。
- 需人工审批或教学过程管理的条款。
- 无法稳定映射到 docx 结构检查/修复动作的制度性表述。

说明：
- 该结论不依赖对扫描 PDF 的逐条 OCR 文本抽取，而依赖本仓现有“规则可执行边界”文件（`docs/IMPLEMENTATION_SCOPE_TASK-003.md`、`docs/V1_OUT_OF_SCOPE_TASK-003.md`）与来源类型定位共同约束。

## 6. 与旧源的冲突事实（保留记录）

来自 `rules/sources/example_thesis_guideline.docx` 的冲突事实：
- 该源给出的“专著、学位论文、报告”示例模板包含“起止页码”字段。
- 其中示例 `[12] ... [D]. ... 98-100.` 明确出现 D 类页码。

本轮处理：
- 不否认旧源示例事实。
- 以 TASK-019 项目决策冻结执行口径：D 类页码改为检查拒绝项（B 类），并显式写入 v3。
