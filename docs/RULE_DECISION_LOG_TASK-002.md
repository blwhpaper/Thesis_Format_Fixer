# RULE_DECISION_LOG_TASK-002

## 1. 决策原则

- 仅冻结规则，不做实现设计扩展。
- 高风险项默认不进 A 类。
- 证据不足时优先降级，不强行“补全规则”。
- 最高优先级声明：**原始依据 > 冻结版规则 > 后续实现**。

## 2. 高风险项决策（为何不进自动修改）

### 2.1 标题层级识别

- 风险：同一文档中编号格式可能与正文数字混用，误判会引发大面积样式误改。
- 决策：仅自动检查（B），不自动重排层级。

### 2.2 自动目录

- 风险：目录域重建会联动分页、页码、样式域，回写成本高。
- 决策：仅检查是否为自动目录（B），不做自动重建（C）。

### 2.3 页码从正文开始

- 风险：依赖分节符与 section 结构，错误回写会破坏全篇页码。
- 决策：检查项 B，不做自动分节重构。

### 2.4 奇偶页不同

- 风险：需要稳定识别页眉页脚多节配置，误改后难恢复。
- 决策：检查项 B，不自动切换全局设置。

### 2.5 脚注按页重编

- 风险：按页重编涉及分页计算与脚注锚点重排，误改风险极高。
- 决策：C（人工复核）。

### 2.6 封皮模板重建

- 风险：当前 PDF 样例文本证据不足，精确布局缺少可验证参数。
- 决策：C（不自动重建，仅存在性/字段检查）。

### 2.7 参考文献排序/年份/语言分组

- 风险：规则含“原则上”与多约束并存，自动改写易改变学术语义与作者原意。
- 决策：B（检测告警），不做自动重排。

## 3. 最终 A/B/C 冻结表

### 3.1 A 类（自动修改）

- 摘要、关键词、正文、标题、参考文献标题与条目、致谢的基础字体字号行距和对齐。
- 页面基础参数：A4、常规页边距、页眉页脚基础样式。
- 脚注基础字体字号行距（可稳定识别时）。

### 3.2 B 类（自动检查不直改）

- 标题层级识别与缩进。
- 自动目录及目录-正文一致性。
- 中英文摘要独立成页。
- 页码起始、页码格式、奇偶页不同。
- 不对称页边距。
- 封皮字段存在性。
- 参考文献排序/年份/语言分组等合规性。
- 装订顺序。

### 3.3 C 类（暂不处理/人工复核）

- 脚注按页重编。
- 自动目录重建。
- 正文起始分节+页码系统重构。
- 奇偶页差异版式自动重构。
- 封皮模板重建。
- 参考文献内容级自动纠错与重排。
- 装订线版面处理。
