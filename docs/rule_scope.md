# Rule Scope

## Scope Definition

- A-class: deterministic, machine-checkable formatting rules.
- B-class: partly machine-checkable rules requiring optional human review.
- C-class: content quality/academic judgment (out of scope).

## Explicit Out-of-Scope for TASK-001

- Actual DOCX fix logic.
- Cover-page reconstruction.
- Page number / section / footnote reflow.
- GUI workflows.
