Thesis Format Fixer

论文格式整理工作台

基于仓内现有单文件 HTTP API 的最小 Appsmith 页面预览。当前优先提供单文件检查/修复闭环，批量处理仍为后续能力。

当前可用

单文件 `check` / `fix`、任务结果读取、技术报告下载、修订稿下载（仅 fix 成功时）

当前预留

批量 HTTP API、任务历史中心、规则在线目录

工作台首页 单文件处理 批量处理（预留） 规则与帮助

工具简介

MVP 主入口

这个工作台面向普通用户，优先提供“上传一个 `.docx` 文件并执行检查或修复”的最小闭环。结果页会按“用户摘要 / 问题明细 / 技术报告”三层展示，避免把技术字段全部堆到同一层。

快速开始

4 步完成
  1. 打开“单文件处理”页并选择一个 `.docx` 文件。
  2. 选择“检查格式”或“修复格式”。
  3. 提交任务后读取 `job_id`，并查询 `GET /api/jobs/{job_id}`。
  4. 成功后查看三层结果，并按真实返回的下载项获取产物。

本地预览提示

保留现有 preview 机制
  • 启动 API：`thesis-format-fixer-api`。
  • 在项目根目录启动静态预览：`python3 -m http.server 9000`。
  • 打开 `http://127.0.0.1:9000/appsmith/preview/index.html`。
  • 单文件页默认请求 `http://127.0.0.1:8000`，可在页面顶部调整。
