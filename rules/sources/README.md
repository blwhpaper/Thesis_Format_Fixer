# Sanitized Source Manifest (Public Repo)

This public repository does not include real institutional policy/source files.

Private source files must be provided locally by end users and must not be committed.

Expected local-only examples:
- `rules/sources/private/example_thesis_guideline.docx`
- `rules/sources/private/example_cover_template.pdf`
- `rules/sources/private/sample_undergraduate_thesis_policy.pdf`

Recommended practice:
- Keep real institution/student/internal files outside version control.
- Use sanitized placeholders in docs/tests.
